# Urban Risk Intelligence Platform
<!-- impeccable:product-schema 1 -->
## Platform
android
## Stack
Java 21 / Spring Boot; React Native com Expo e TypeScript; web para demonstração no Windows. PostgreSQL via Docker e H2 persistente para execução local sem Docker.
## Users
Moradores e agentes locais, conforme enunciado. Aplicação acadêmica.
## Product Purpose
Monitorar alagamentos, calor extremo e interrupções de energia, priorizar alertas explicáveis e preservar a consulta durante indisponibilidade da API.
## Operating Context
Android e navegador no Windows. Demonstração com backend parado e reconectado. Dados simulados, sem integração com órgãos públicos nesta versão.
## Capabilities and Constraints
API REST, persistência, origem e confiança, painel, lista de eventos, avisos em primeiro plano, análise determinística. Não oferece previsão meteorológica nem despacho de emergência. Nenhum dado pessoal é necessário.
## Product Principles
Prioridade compreensível; dados antigos visíveis como antigos; falha de rede recuperável; simulação sempre explícita.
## Accessibility & Inclusion
Português, texto acompanhando as cores de severidade, alvos de toque de 48 dp e suporte ao tamanho de fonte do sistema.
